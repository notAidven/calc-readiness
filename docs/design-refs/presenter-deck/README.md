# Presenter deck source

`Color_scheme_lightened (2).pptx` is the owner-provided visual source deck for
the embedded presenter flow. The four 1600×900 browser assets under
`apps/web/public/presenter-deck/` are direct exports of its four slides.

The PowerPoint file is the editing source. Regenerate the PNGs after changing
it; do not redraw the slides in application CSS or allow the browser version
to drift from the deck used by the presenters.
