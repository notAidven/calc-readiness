# Care House production frames

Whole learner-surface captures from `CitySurface` with the real WebGL island mounted. The Care
House enters through the same city-menu and Oru briefing path used by the production mount.

| Frame | Viewport | State |
| --- | --- | --- |
| `01-announcement-1024x580.png` | 1024×580 | Oru, first of three short onboarding steps |
| `02-treat-1024x580.png` | 1024×580 | Treat selected, question 1 |
| `03-prepare-1024x580.png` | 1024×580 | Prepare selected, question 1 |
| `04-correct-consequence-1024x580.png` | 1024×580 | correct Prepare result; supply rack/count increase |
| `05-incorrect-consequence-1024x580.png` | 1024×580 | incorrect Prepare result; supply remains absent |
| `06-best-ending-1024x580.png` | 1024×580 | perfect P-T-T play, 5 of 5 cared for |
| `07-partial-ending-1024x580.png` | 1024×580 | P-T-T at 2/3 each round, 4 of 5 cared for |
| `08-choosing-390x580.png` | 390×580 | responsive action choice, both actions and return visible |
| `09-reduced-motion-1024x580.png` | 1024×580 | settled correct consequence with motion disabled |

The frames were opened and inspected at their named viewports. The island remains visible around
the Care House rail, the 390×580 action choice fits without hiding either action, the best and
partial outcomes differ plainly, and correct/incorrect results change the care scene as well as
the text.
